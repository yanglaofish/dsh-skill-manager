# 2.x 修复计划与验证记录

目标：修复审查确认的缺陷，优先保证会话选择影响真实技能目录和加载工具。
保持技能库共享、工作区启用、会话独立自选及只读预设的既有产品规则。
用户已要求实施；在现有 dsh2.x 分支修复。本机 desktop profile 已由用户授权改为本地 junction；发布由后续用户授权决定。

## 实施顺序

- [x] 会话：在 agent scope 注册 provider；显式选择覆盖可管理用户技能的 invocation，
  未勾选的技能不能从 skill 工具或用户直接调用路径加载；跟随工作区不覆写原生行为。
  保留预设、资源基目录和技能本身的 invocation 限制。刷新使下一次执行读取新状态。
- [x] 存储：同一个 DSH_HOME 的写入跨进程串行化；JSON 临时写入后替换；损坏文件不静默清空。
  会话状态使用 profile 命名空间，保留旧会话状态的读取兼容；共享库/工作区不按 profile 拆分。
- [x] 文件操作：拒绝绝对路径/目录链接越界和非法技能标识符；先在同文件系统临时目录完整准备，
  成功后替换并保留旧版本；失败不覆盖旧内容。收纳冲突不覆盖或移除来源；删除保留独立来源。
- [x] 来源校验：管理页按 host:port 隔离，保留桌面桥接和本地无 Origin 调用。
- [x] 验证：隔离单测、真实 DSH 注册表/skill 工具、双会话/双进程、失败与回滚、卸载重载，
  更新文档与审查复现脚本，检查差异。

## 测试范围

同工作区两个会话独立、跟随恢复、空选集、预设同名、重启读取、更新后缓存失效；
同名技能不同内容、非法压缩包、写入中断、符号链接、Windows 路径、多 profile 并发登记。
所有写入测试均使用独立临时 DSH_HOME 和 DSH_AGENTS_HOME。
